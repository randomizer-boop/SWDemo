# StarWise — демо для портфолио

Демо-версия Telegram Mini App StarWise (натальная карта). Работает без бэкенда:
показывает путь пользователя на вымышленном профиле.

## Что внутри

- Фронтенд мини-аппа (React + Vite) — те же экраны, что в рабочей версии.
- Демо-профиль: Ташкент, 27.04.1997, 07:30. Карта рассчитана движком проекта
  (Swiss Ephemeris, дома Плацидус) и сохранена статически в `src/demo/demoChart.js`.
- Бесплатный разбор «Кто ты» открыт (`src/demo/demoData.js`), платные разборы и
  прогноз дня закрыты пейволлом.
- На десктопе — страница с описанием и приложением в рамке телефона
  (пропорция экрана 390×844, масштабируется под высоту окна),
  на телефоне — приложение с полоской «Демо».
- Два языка: RU / EN. Переключатель — на странице демо и в мобильной полоске;
  по умолчанию язык берётся из браузера.

## Языки

Русская строка служит ключом: `t("Назад")` → «Назад» / “Back”.
Переводы лежат в `src/i18n/en.js`, тексты бесплатного разбора на двух
языках — в `src/demo/demoData.js`. Новая строка в интерфейсе: обернуть в
`t("…")` и добавить перевод в `en.js`.

## Ссылки и демо-админка

Всё в `src/demo/config.js`:

- `BOT_URL` — бот в Telegram (сейчас `https://t.me/star_wise_bot`).
- `TIKTOK_URL` — TikTok проекта. Пока пусто — ссылка не показывается.
- `ADMIN_DEMO_URL` — демо админ-панели, файл `public/admin-demo.html`
  (тот же интерфейс, что у рабочей админки, но данные вымышленные и живут в памяти страницы).
  На сайте открывается по адресу `/admin-demo.html`.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Деплой на Vercel

1. Залить папку в новый репозиторий GitHub.
2. Vercel → Add New → Project → выбрать репозиторий. Framework: Vite
   (определяется автоматически), настройки по умолчанию.
3. Добавить `VITE_BOT_URL`, если ссылка не вписана в код.

## Отличия от рабочего фронтенда

| Файл | Что изменено |
|---|---|
| `src/lib/api.js` | Вместо запросов к FastAPI — статичные ответы в том же формате |
| `src/demo/*` | Демо-данные, страница с рамкой телефона, полоска, сброс |
| `src/main.jsx` | Выбор: страница демо (десктоп) или приложение (телефон / iframe) |
| `src/App.jsx` | Имя демо-профиля, форма с готовыми данными, переходы по экранам |
| `src/pages/BirthForm.jsx` | Поля заполнены и закрыты от правок |
| `src/pages/CategoryScreen.jsx` | Подключён разбор «Кто ты», подпись под пейволлом |
| `src/pages/TeaserReading.jsx` | Новый экран разбора «Кто ты»: формула, три точки, карточки |
| `src/i18n/*` | Локализация RU / EN |
| `src/components/DevScreenSwitcher.*` | Удалён (режим разработчика) |
| `src/pages/ForecastScreen.jsx` | Подпись под пейволлом |
| `index.html` | Убран Telegram SDK (страница открывается в браузере) |
